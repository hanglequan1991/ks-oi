## Preconditions
- The owner created the D1 database and bound it in `wrangler.jsonc`; `LIVE_D1_DATABASE` names a disposable or staging database (never the production one) and `CLOUDFLARE_API_TOKEN` is set.
- `npx wrangler` is available in `sheet-rag/`.

## Steps
1. Run `npx wrangler d1 migrations apply $LIVE_D1_DATABASE --remote`.
2. Run the same command again.
3. Run `npx wrangler d1 execute $LIVE_D1_DATABASE --remote --json --command "SELECT name FROM sqlite_master WHERE type='table'"`.
4. Run `... --command "SELECT key, value FROM settings"`.
5. Update `service_fee_percent` to `12` with `d1 execute`, run `migrations apply` again, read the setting.
6. Restore the value to `10`.

## Expected results
1. Exit code 0; all migration files are applied.
2. Exit code 0; reports nothing left to apply.
3. All required tables of TC-1 exist (D1 may add internal tables such as `d1_migrations`, which are ignored).
4. 5 seeded keys; fee `10`, fee note `true`, both disclaimers equal to the literals used in TC-4.
5. The value stays `12`.
6. The value is back to `10` (cleanup; run in a `finally` block).
