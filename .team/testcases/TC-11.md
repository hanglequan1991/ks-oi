# TC-11: Pages open in Vietnamese at the normal address and in English under /en/

- id: TC-11
- story: [STORY-16](../stories/STORY-16.md)
- verifies: AC1, AC2, AC4
- status: done
- assignee: qa
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-11.e2e.ts`
- runs without Cloudflare credentials: yes (Node HTTP server around `createApp`, Playwright browser)

## Preconditions
- TASK-6 to TASK-14 are done; Playwright and its Chromium browser are installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. Sample route `/sample` (no price) is mounted.
- `CLOUDFLARE_API_TOKEN` is unset. The browser context is fresh (no cookies, empty localStorage).

## Steps
1. Open `/sample` in a fresh browser context.
2. Read the `lang` attribute of `<html>`, the visible page title/heading, and the toggle link text.
3. Open `/en/sample` in the same context.
4. Read the same three values, plus `link[rel=canonical]` and the `link[rel=alternate][hreflang]` elements.
5. Negative: request `/english` and `/en-US/sample` with the request API.

## Expected results
1. The page loads with HTTP 200.
2. `<html lang="vi">`; the visible texts are the Vietnamese dictionary values (for example "Tiếng Việt" language label); the toggle link points to `/en/sample`.
3. `/en/sample` loads with HTTP 200.
4. `<html lang="en">`; texts are the English dictionary values; the toggle link points to `/sample`; canonical is `<origin>/en/sample`; alternates exist for `vi` (`/sample`), `en` (`/en/sample`) and `x-default` (`/sample`).
5. `/english` and `/en-US/sample` are treated as Vietnamese pages (or 404), never as English: if the response is HTML its `lang` is `vi`.
6. Nothing in the first visit (no cookie, no storage) changed the language: step 2 result is Vietnamese (AC4, server side).

## Test data
- Paths: `/sample`, `/en/sample`, `/english`, `/en-US/sample`.
- Sample settings: `disclaimerVi` "VI-SAMPLE-DISCLAIMER", `disclaimerEn` "EN-SAMPLE-DISCLAIMER", `showFeeNote` false.
