# TC-12: Switching language is remembered on reload and on a later visit in the same browser

- id: TC-12
- story: [STORY-16](../stories/STORY-16.md)
- verifies: AC3
- status: todo
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-12.e2e.ts`
- runs without Cloudflare credentials: yes (real browser, `public/lang.js` served by the Node harness)

## Preconditions
- TASK-6 to TASK-14 are done (TASK-10 provides `public/lang.js`); Playwright and Chromium installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. Sample route `/sample` is mounted (supports a query string, for example `/sample?x=1#top`).
- One persistent browser context is used for the whole test (same localStorage); localStorage starts empty.

## Steps
1. Open `/sample` (Vietnamese). Click the language toggle link (`a[data-lang="en"]`).
2. Read the URL, `<html lang>` and `localStorage.hd_lang`.
3. Reload the page.
4. Open `/sample?x=1#top` in a new tab of the same context.
5. Click the toggle `a[data-lang="vi"]` on the English page.
6. Read URL, `lang` and `hd_lang`; then open `/en/sample` directly in a new tab.
7. Open the root path `/` (mounted sample page) after setting `hd_lang=en`, then `/en/` after setting `hd_lang=vi`.
8. Close the page, create a new page in the same context ("return later"), open `/sample` after `hd_lang=en` was last chosen.

## Expected results
1. The click navigates to `/en/sample` as a normal link.
2. URL `/en/sample`, `lang="en"`, `hd_lang === "en"`.
3. After reload the page is still `/en/sample` in English (no flicker back to Vietnamese in the final state).
4. The tab ends on `/en/sample?x=1#top`: language prefix added, search and hash kept.
5. The click navigates to `/sample`.
6. URL `/sample`, `lang="vi"`, `hd_lang === "vi"`; the direct visit to `/en/sample` is redirected to `/sample` because Vietnamese is remembered.
7. `/` with saved `en` lands on `/en/`; `/en/` with saved `vi` lands on `/`.
8. The new page lands on `/en/sample` (English) with no redirect loop (navigation count stays small, page settles).

## Test data
- Storage key `hd_lang`, values `vi` and `en`.
- Paths: `/`, `/en/`, `/sample`, `/en/sample`, `/sample?x=1#top`.

## QA notes
<!-- Written by qa: anything the reviewer should know, product bugs found. -->
- Automated in `sheet-rag/e2e/TC-12.e2e.ts` (one test, one persistent context). Passes on `--project=chromium`. No product bugs found.
- Harness deviation (test-only, no product code touched): step 7 says `/` is "mounted sample page", but the precondition mounts only `/sample`. Without a mount, `/` and `/en/` are plain 404s with no `lang.js`, so no redirect could happen. The harness therefore also mounts the sample page at `/` and `/en/`.
- Step 8 says "after hd_lang=en was last chosen", but step 7 leaves `vi` stored. The test sets `en` explicitly before step 8.
- `common.siteName` is "Sheet RAG" in both languages, so the test checks `main p` (`common.langVi`: "Tiếng Việt" vs "Vietnamese") as the language signal.
- Step 8 navigation count is checked as at most 2 main-frame navigations (the `/sample` commit plus the `lang.js` replace).
