# TC-13: First visit with nothing stored, or an invalid stored value, stays in Vietnamese

- id: TC-13
- story: [STORY-16](../stories/STORY-16.md)
- verifies: AC4
- status: done
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-13.e2e.ts`
- runs without Cloudflare credentials: yes

## Preconditions
- TASK-6 to TASK-14 done; Playwright and Chromium installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. Sample route `/sample` is mounted.
- Browser context with a browser language of English (`locale: 'en-US'`, `Accept-Language: en-US`) to prove the browser language is not used to pick the site language.

## Steps
1. Open `/sample` in a fresh context with locale `en-US`; record every navigation (listen to `framenavigated`).
2. Read `<html lang>`, `localStorage.hd_lang`, and the URL.
3. In a second fresh context set `hd_lang` to `fr` (init script) and open `/sample`.
4. In a third fresh context set `hd_lang` to an empty string and open `/sample`.
5. In a fourth context disable JavaScript (`javaScriptEnabled: false`) and open `/sample`.

## Expected results
1. The page loads at `/sample` with a single navigation (no redirect).
2. `lang="vi"`, `hd_lang` is still null (the script wrote nothing), URL unchanged.
3. Unknown value `fr`: no redirect, `lang="vi"`, URL `/sample`.
4. Empty value: no redirect, `lang="vi"`.
5. With JavaScript off the page is Vietnamese and the toggle link to `/en/sample` is present and works as a plain link (request it and get HTTP 200 with `lang="en"`).

## Test data
- Stored values: none, `fr`, empty string.
- Browser locale: `en-US`.

- Steps 3 and 4 also asserting that the stored value is unchanged: judged faithful. Expected result 2 defines "the script wrote nothing" for the no-value case. For an unknown value the story intent is "ignored", and an ignored value must not be rewritten or cleared. The extra check does not contradict the TC and does not make the test brittle. Accepted. - Non-blocking observation: the navigation count for steps 3 and 4 is read right after the assertions pass, so a very late script redirect could in theory be missed. Acceptable because lang.js runs synchronously and the lang assertion would also fail on a redirect to `/en/sample`.
