# TC-14: Pages still work when the browser blocks storage

- id: TC-14
- story: [STORY-16](../stories/STORY-16.md)
- verifies: AC5
- status: todo
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-14.e2e.ts`
- runs without Cloudflare credentials: yes

## Preconditions
- TASK-6 to TASK-14 done; Playwright and Chromium installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. Sample routes `/sample` and `/priced` (with a price) are mounted.
- Storage is blocked with a Playwright init script that makes `window.localStorage` getter throw a `SecurityError` (variant A) and, in variant B, makes `getItem` and `setItem` throw.

## Steps
1. Variant A: add the init script, listen to `pageerror` and `console` errors, open `/sample`.
2. Variant A: open `/en/sample`.
3. Click the language toggle on the Vietnamese page.
4. Variant B (getItem/setItem throw): repeat steps 1 to 3.
5. Open `/en/priced` under blocked storage.

## Expected results
1. `/sample` is shown in Vietnamese (`lang="vi"`), no redirect, no `pageerror`.
2. `/en/sample` stays in English (`lang="en"`): the language of the address is kept, no redirect, no `pageerror`.
3. The click still navigates to `/en/sample` (link is not blocked by script) and the page is English; nothing is remembered, so a reload keeps the address language.
4. Same results as 1 to 3 for variant B.
5. The priced page renders its price and the English disclaimer normally.

## Test data
- Both blocking variants described above; paths `/sample`, `/en/sample`, `/en/priced`.
