## Preconditions
- TASK-7 and TASK-9 done; Playwright installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. Sample routes `/sample` and `/en/sample` are mounted (the test also mounts `/priced` and `/en/priced`).

## Steps
1. Import `vi` and `en` from `sheet-rag/src/web/i18n/` and flatten both to dot-path keys.
2. Compare the key sets in both directions; check every leaf is a non-empty string; compare the `{placeholder}` names per key.
3. Check the required keys exist: `common.siteName`, `common.langVi`, `common.langEn`, `common.switchToVi`, `common.switchToEn`, `common.skipToContent`, `price.feeNote`, `price.currencyUnit`, `price.perNight`, `errors.tooManyRequests`, `errors.inputTooLong`, `errors.notFound`, `errors.generic`.
4. Fetch `/sample` and `/en/sample` and check no visible text equals a raw dictionary key (for example the string `common.siteName` or `price.feeNote` is never shown).
5. Check the Vietnamese values contain Vietnamese diacritics where expected (for example `common.langVi` is "Tiếng Việt") and the English file has no Vietnamese-only characters, except `common.switchToVi` ("Chuyển sang tiếng Việt"), which en.ts deliberately holds in Vietnamese (it is the label that switches to Vietnamese); that key is excluded from the check and asserted to be Vietnamese.

## Expected results
1. Both objects load.
2. Key sets are identical, no empty leaf, identical placeholder names (`{percent}` in `price.feeNote`).
3. All required keys exist in both languages.
4. Neither page shows a raw key.
5. Vietnamese text has diacritics; English text has none of the Vietnamese-only letters (bar the `common.switchToVi` exception).

## Test data
- Required keys listed in step 3.
