# TC-16: Every page that shows a price carries the call-to-confirm disclaimer in the page language

- id: TC-16
- story: [STORY-16](../stories/STORY-16.md)
- verifies: AC7
- status: done
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-16.e2e.ts`
- runs without Cloudflare credentials: yes

## Preconditions
- TASK-8, TASK-9 and TASK-14 done; Playwright and Chromium installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. Sample routes: `/priced` and `/en/priced` (Layout with `showsPrice` and a `PriceBlock` of 1375000), `/priced-two` and `/en/priced-two` (two `PriceBlock`s, for step 7), `/sample` (no price), and `/broken` (renders a `PriceBlock` but with `showsPrice` false, so the guard must trigger).

## Steps
1. Open `/priced` in a browser; locate `[data-disclaimer]` and `[data-price]`.
2. Open `/en/priced`; locate the same elements.
3. Open `/sample` (no price).
4. Request `/broken`.
5. Variant: set `disclaimerVi` empty in settings and open `/priced`; then set both empty and open `/priced`.
6. Variant: set `disclaimerEn` text to `<b>x</b>` and open `/en/priced`.
7. Open `/priced-two` (two prices, one page); count `[data-price]` and `[data-disclaimer]`.

## Expected results
1. Exactly one `[data-disclaimer]` with the Vietnamese sample text "VI-SAMPLE-DISCLAIMER", visible in the page; the price is shown as `1.375.000 ₫`.
2. Exactly one `[data-disclaimer]` with "EN-SAMPLE-DISCLAIMER"; the price is shown as `1,375,000 VND`.
3. The price-free page has no price and no disclaimer requirement (no error).
4. `/broken` is not served with a price lacking a disclaimer: the response is a 500 (security headers still present), and its body contains no `data-price`.
5. Empty Vietnamese text falls back to the English text; with both empty the page answers 500 instead of silently omitting the notice.
6. The `<b>` is displayed as literal text (escaped), no `<b>` element exists inside the disclaimer.
7. The disclaimer is rendered once per page, not once per price (open `/priced-two`, which has two `PriceBlock`s: 2 `[data-price]`, still 1 `[data-disclaimer]`).

## Test data
- Amount 1375000; sample disclaimer texts as above.
