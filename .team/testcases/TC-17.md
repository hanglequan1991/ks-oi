## Preconditions
- TASK-7, TASK-8, TASK-9, TASK-14 done; Playwright and Chromium installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. The fake `getSettings` reads a mutable object so each step can change `showFeeNote` and `serviceFeePercent`. Sample route `/priced` is mounted.

## Steps
1. Settings: `showFeeNote` true, `serviceFeePercent` 10. Open `/en/priced`.
2. Same settings, open `/priced`.
3. Set `showFeeNote` false; open `/en/priced` and `/priced`.
4. Set `showFeeNote` true, `serviceFeePercent` 12.5; open `/en/priced`.
5. Open `/sample` and `/en/sample` (no price) with `showFeeNote` true.

## Expected results
1. `[data-fee-note]` exists next to the price (inside the `[data-price]` element, as rendered by PriceBlock) with the exact text "Includes 10% service fee".
2. `[data-fee-note]` exists with the Vietnamese text "Đã bao gồm 10% phí dịch vụ".
3. No `[data-fee-note]` on either page; the price and the disclaimer are still shown.
4. The note reads "Includes 12.5% service fee" (percentage comes from settings, not hard-coded).
5. No fee note appears on a page without a price, in either language.

## Test data
- Percentages 10 and 12.5; flag on and off.
