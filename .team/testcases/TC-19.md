# TC-19: Security headers are present on every response and the CSP does not break the pages

- id: TC-19
- story: [STORY-16](../stories/STORY-16.md)
- verifies: AC12
- status: todo
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-19.e2e.ts`
- runs without Cloudflare credentials: yes

## Preconditions
- TASK-9, TASK-10, TASK-11, TASK-14 done; Playwright and Chromium installed.
- Harness (inline in the test file, no shared helper): a Node `http` server on port 0 that converts each request to a `Request`, calls `createApp(deps).fetch`, and also serves `sheet-rag/public/lang.js` and `app.css` as static files (stands in for the Workers assets binding). `deps.getSettings` is a fake returning sample `SiteSettings` with distinct sample texts. `mount` registers sample routes using `Layout` and `renderPage`. Mounted routes: `/sample`, `/priced`, `/api/hotels` (JSON), `/boom` (throws), unknown path (404). `/api/hotels` has a small injected limiter (limit 1) to produce a 429.

## Steps
1. Request an HTML page, the JSON route, a 404, the throwing route (500) and a 429 (second request to the limited route from one IP).
2. For each response read the five headers.
3. Inspect the CSP string.
4. Open `/sample` and `/en/priced` in a browser, collect `console` messages and `securitypolicyviolation` events; click the language toggle.
5. Make `getSettings` reject and open `/priced`.

## Expected results
1. Statuses 200, 200, 404, 500 and 429 respectively.
2. All five responses carry: `X-Content-Type-Options: nosniff`; `Referrer-Policy: strict-origin-when-cross-origin`; `Strict-Transport-Security: max-age=31536000; includeSubDomains`; `X-Frame-Options: DENY`; and a `Content-Security-Policy`.
3. The CSP contains `script-src 'self'`, `style-src 'self'`, `img-src 'self' https:`, `default-src 'none'`, `frame-ancestors 'none'`; it contains neither `unsafe-inline` nor `unsafe-eval`.
4. No CSP violation or console error occurs: `/lang.js` and `/app.css` load, the toggle works, and the page HTML has no inline `<script>` content and no `style=` attribute.
5. The settings failure gives a 500 response that still carries the five headers and does not crash the server.
6. The static files `/lang.js` and `/app.css` served through the harness are not required to have the headers here (live assets are covered in TC-23).

## Test data
- Header values as written in step 2 and 3.
