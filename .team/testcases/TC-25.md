# TC-25: Hotel list returns only published hotels with final prices, in pages

- id: TC-25
- story: [STORY-15](../stories/STORY-15.md)
- verifies: AC1
- status: deferred
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-25.e2e.ts`
- runs without Cloudflare credentials: yes (Node HTTP server around `createApp` + `mountApi`, fake D1, real migrations)

## Preconditions
- TASK-14, TASK-16, TASK-18 to TASK-25 done; Playwright installed (uses the Playwright `request` fixture, no browser page).
- Harness (inline in the test file, no shared helper): fresh fake D1 from `test/fakes`, `applyMigrations`, `seedApiSample` (TASK-16); a Node `http` server on port 0 that converts each request to a `Request` and calls `createApp({ getSettings, mount: mountApi({ db, getSettings }) }).fetch` with the real `getSettings` from `src/db/settings.ts`. Each test file builds its own database and server, so files can run in parallel.
- Each request sets its own `CF-Connecting-IP` (a unique address per test) so the `data` limit (60 per minute) is never reached by accident.

## Steps
1. `GET /api/hotels` on the sample data (5 hotels: 3 published, 1 review, 1 hidden).
2. Read `items`, `page`, `limit`, `total`, `totalPages`, and the `Cache-Control` header.
3. Call `seedManyPublished(db, 60)`, then `GET /api/hotels?limit=50&page=1` and `?limit=50&page=2`.
4. Request a page past the end (`?page=99`).
5. On a database with no published hotel (delete the three published rows first), `GET /api/hotels`.

## Expected results
1. Status 200, `Content-Type` JSON.
2. `items` holds exactly `mong-hotel`, `sao-hotel`, `dong-do-hotel`; `total` 3, `page` 1, `limit` 20, `totalPages` 1; `Cache-Control: public, max-age=60`. `mong-review`, `mong-hidden`, `Mộng Review` and `Mộng Hidden` appear nowhere in the body.
3. Page 1 has 50 items, page 2 has 13 (63 published in total), `totalPages` 2, and no slug appears on both pages.
4. 200 with empty `items` (no error), `total` 63.
5. `items` empty, `total` 0, `totalPages` 0.
6. Each item carries a `price` object (final price) or `null`, see TC-30 for the values.

## Test data
- Fixture slugs `mong-hotel` (h1), `sao-hotel` (h2), `dong-do-hotel` (h3), `mong-review` (h4), `mong-hidden` (h5); `bulk-1..bulk-60` in `ha-noi`.
