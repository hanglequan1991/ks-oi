## Preconditions
- TASK-14, TASK-16, TASK-18 to TASK-25 done; Playwright installed (uses the Playwright `request` fixture, no browser page).
- Harness (inline in the test file, no shared helper): fresh fake D1 from `test/fakes`, `applyMigrations`, `seedApiSample` (TASK-16); a Node `http` server on port 0 that converts each request to a `Request` and calls `createApp({ getSettings, mount: mountApi({ db, getSettings }) }).fetch` with the real `getSettings` from `src/db/settings.ts`. Each test file builds its own database and server, so files can run in parallel.
- Each request sets its own `CF-Connecting-IP` (a unique address per test) so the `data` limit (60 per minute) is never reached by accident.

## Steps
1. `GET /api/hotels?city=da-nang`.
2. `GET /api/hotels?stars=5`, then `?stars=4`.
3. `GET /api/hotels?facility=pool`, then `?facility=parking`.
4. `GET /api/hotels?q=mong`, `?q=M%E1%BB%99ng` (Mộng), `?q=MONG`, `?q=dong%20do`, `?q=%C4%90%C3%B4ng` (Đông).
5. Combine: `?city=da-nang&facility=pool&stars=5`, and `?city=ha-noi&stars=5`.
6. `GET /api/hotels?q=zzz-no-match`.
7. `GET /api/hotels?city=hue` (the city only has a hidden hotel).

## Expected results
1. `mong-hotel` and `dong-do-hotel` only (`mong-review` is also in da-nang but never returned).
2. stars=5 gives `dong-do-hotel`; stars=4 gives `mong-hotel`.
3. pool gives `mong-hotel` and `dong-do-hotel`; parking gives `mong-hotel` and `sao-hotel`. The unconfirmed parking flag of `mong-hotel` (confirmed 0) is a fixture detail: qa records in QA notes whether the API treats it as a match and asserts what the story allows (listed facility = match), flagging any doubt to qalead.
4. `mong`, `Mộng` and `MONG` each return exactly `mong-hotel` (not the review or hidden Mộng hotels); `dong do` and `Đông` return `dong-do-hotel`.
5. The combination returns only `dong-do-hotel`; the second returns empty `items`, `total` 0.
6. 200, empty `items`, `total` 0.
7. Empty `items` (hidden hotels never count), 200.
8. `total` equals the number of `items` in every single-page answer above.

## Test data
- Fixture hotels as in TC-25. Search text is matched against `name_search` (accent folded).
