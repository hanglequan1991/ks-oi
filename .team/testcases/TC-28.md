# TC-28: Hotel detail returns facilities, images, rooms and booking rules with sync dates, text unchanged

## Preconditions
- TASK-14, TASK-16, TASK-18 to TASK-25 done; Playwright installed (uses the Playwright `request` fixture, no browser page).
- Harness (inline in the test file, no shared helper): fresh fake D1 from `test/fakes`, `applyMigrations`, `seedApiSample` (TASK-16); a Node `http` server on port 0 that converts each request to a `Request` and calls `createApp({ getSettings, mount: mountApi({ db, getSettings }) }).fetch` with the real `getSettings` from `src/db/settings.ts`. Each test file builds its own database and server, so files can run in parallel.
- Each request sets its own `CF-Connecting-IP` (a unique address per test) so the `data` limit (60 per minute) is never reached by accident.

## Steps
1. `GET /api/hotels/mong-hotel`.
2. `GET /api/hotels/mong-hotel?lang=en`.
3. `GET /api/hotels/dong-do-hotel` (no rooms, no images) and `/api/hotels/sao-hotel` (no rules).
4. `GET /api/hotels/mong-hotel?lang=fr`.

## Expected results
1. 200, `Cache-Control: public, max-age=60`. The body has the hotel name, city, stars, address, description, `facilities` (pool and parking with Vietnamese labels), `images` (2, in position order, alt text on the first), `rooms` (2: `Deluxe` then `Standard`, in position order), and `bookingRules`.
2. Booking rules: the hotel-level rule has `syncedAt` `2026-11-17T02:00:00Z` and a text equal byte for byte to the seeded `Nhận phòng 14:00\n  Trả phòng 12:00 (có dấu cách thừa) ` (newline, inner spaces and trailing space kept, no trimming or rewriting). The `Deluxe` room-level rule has its own text and `syncedAt` `2026-11-16T02:00:00Z`; `Standard` has no rule.
3. With `lang=en` the description, city name (`Da Nang`) and facility labels (Swimming pool, Parking) are English; rule text stays as stored (not translated).
4. `dong-do-hotel` returns 200 with `rooms: []` and `images: []`; `sao-hotel` returns 200 with no hotel-level rules (empty list or absent, as TASK-18 defines) and no error.
5. `lang=fr` returns 400 `invalid_param`.
6. The body also contains both disclaimer texts from the settings (TASK-23).

## Test data
- Fixture `mong-hotel` (h1) rules and images as in TASK-16.
