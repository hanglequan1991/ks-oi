# TC-29: Hotel detail is "not found" for review, hidden, unknown and malformed slugs

- id: TC-29
- story: [STORY-15](../stories/STORY-15.md)
- verifies: AC5
- status: deferred
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-29.e2e.ts`
- runs without Cloudflare credentials: yes (Node HTTP server around `createApp` + `mountApi`, fake D1, real migrations)

## Preconditions
- TASK-14, TASK-16, TASK-18 to TASK-25 done; Playwright installed (uses the Playwright `request` fixture, no browser page).
- Harness (inline in the test file, no shared helper): fresh fake D1 from `test/fakes`, `applyMigrations`, `seedApiSample` (TASK-16); a Node `http` server on port 0 that converts each request to a `Request` and calls `createApp({ getSettings, mount: mountApi({ db, getSettings }) }).fetch` with the real `getSettings` from `src/db/settings.ts`. Each test file builds its own database and server, so files can run in parallel.
- Each request sets its own `CF-Connecting-IP` (a unique address per test) so the `data` limit (60 per minute) is never reached by accident.

## Steps
1. `GET /api/hotels/mong-review` and `/api/hotels/mong-hidden`.
2. `GET /api/hotels/khong-co`.
3. Malformed slugs: `/api/hotels/MONG-HOTEL` (uppercase), `/api/hotels/m%C3%B4ng`, `/api/hotels/a%20b`, `/api/hotels/%27%20OR%201%3D1`, a 101-character slug, `/api/hotels/..%2F..%2Fetc`.
4. Change `mong-hotel` to `hidden` in the database, request it, then set it back to `published`.

## Expected results
1. Both return 404 with JSON `{"error":{"code":"not_found","message":"Hotel not found"}}`. The body does not contain the hotel name, status or price. No `Cache-Control: public` header on the 404.
2. Same 404 body for an unknown slug (an attacker cannot tell a hidden hotel from a missing one: the three bodies are identical).
3. Every malformed slug returns 404 (not 500, not 400 data leak).
4. After the status change the same request returns 404; after restoring it, 200 again (status is read live, not cached).

## Test data
- Fixture slugs `mong-review` (room base 555000) and `mong-hidden` (room base 444000); neither number may appear in any response.
