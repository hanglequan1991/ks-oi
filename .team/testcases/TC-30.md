# TC-30: Room price is the final price (1,250,000 becomes 1,375,000) and an unpriced room has no price

- id: TC-30
- story: [STORY-15](../stories/STORY-15.md)
- verifies: AC6, AC8
- status: todo
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-30.e2e.ts`
- runs without Cloudflare credentials: yes (Node HTTP server around `createApp` + `mountApi`, fake D1, real migrations)

## Preconditions
- TASK-14, TASK-16, TASK-18 to TASK-25 done; Playwright installed (uses the Playwright `request` fixture, no browser page).
- Harness (inline in the test file, no shared helper): fresh fake D1 from `test/fakes`, `applyMigrations`, `seedApiSample` (TASK-16); a Node `http` server on port 0 that converts each request to a `Request` and calls `createApp({ getSettings, mount: mountApi({ db, getSettings }) }).fetch` with the real `getSettings` from `src/db/settings.ts`. Each test file builds its own database and server, so files can run in parallel.
- Each request sets its own `CF-Connecting-IP` (a unique address per test) so the `data` limit (60 per minute) is never reached by accident.
- Seeded fee setting is 10 percent (TASK-3 default).

## Steps
1. `GET /api/hotels/mong-hotel`; read the `Deluxe` and `Standard` rooms.
2. `GET /api/hotels/sao-hotel`; read the `Superior` room.
3. `GET /api/hotels`; read `price` of each item.
4. Set the fee to 12 (`UPDATE settings SET value='12' WHERE key='service_fee_percent'`) and read `sao-hotel` again (980000 x 1.12 = 1,097,600).
5. Set the fee to 7 and read `sao-hotel` (980000 x 1.07 = 1,048,600). Restore the fee to 10.
6. Search every response body for a price of `0` (`"amount":0`) and for `"price":0`.

## Expected results
1. `Deluxe` has `price.amount` 1375000, `currency` `VND`, `unit` `night` (a number, not a string). `Standard` has `price: null` (the key is present and null, not 0, not absent-as-zero).
2. `Superior` has `price.amount` 1078000.
3. In the list, `mong-hotel` has `price.amount` 1375000 (lowest priced room), `sao-hotel` 1078000, `dong-do-hotel` (no rooms) `price: null`.
4. Rounded to the nearest 1,000: 1098000.
5. 1049000 (rounding up from 1,048,600).
6. No response contains a price of 0 for any hotel or room.

## Test data
- Base prices 1250000 (Deluxe), 980000 (Superior), NULL (Standard); they are only used to compute expectations in the test and must not be asserted as response content (see TC-37).
