# TC-32: The fee note flag controls whether the fee percentage is stated with a price

- id: TC-32
- story: [STORY-15](../stories/STORY-15.md)
- verifies: AC10
- status: todo
- rework count: 0
- automation test file: `sheet-rag/e2e/TC-32.e2e.ts`
- runs without Cloudflare credentials: yes (Node HTTP server around `createApp` + `mountApi`, fake D1, real migrations)

## Preconditions
- TASK-14, TASK-16, TASK-18 to TASK-25 done; Playwright installed (uses the Playwright `request` fixture, no browser page).
- Harness (inline in the test file, no shared helper): fresh fake D1 from `test/fakes`, `applyMigrations`, `seedApiSample` (TASK-16); a Node `http` server on port 0 that converts each request to a `Request` and calls `createApp({ getSettings, mount: mountApi({ db, getSettings }) }).fetch` with the real `getSettings` from `src/db/settings.ts`. Each test file builds its own database and server, so files can run in parallel.
- Each request sets its own `CF-Connecting-IP` (a unique address per test) so the `data` limit (60 per minute) is never reached by accident.
- Seeded `show_fee_note` is `true` and the fee is 10 (TASK-3 defaults).

## Steps
1. With the defaults, `GET /api/hotels/mong-hotel` and `GET /api/hotels`; read every `price` object.
2. `UPDATE settings SET value='false' WHERE key='show_fee_note'`; request both again.
3. Set the fee to 15 with the note on; request both again.
4. Set `show_fee_note` to a non-boolean (`yes`, empty); request `/api/hotels/mong-hotel` and `/api/config`.

## Expected results
1. Every non-null price has `includesFeePercent` equal to 10; `price: null` entries have no such key.
2. No `includesFeePercent` key appears anywhere in either response (key absent, not null, not 0); amounts unchanged (1375000).
3. `includesFeePercent` is 15 and the Deluxe amount is 1437500 rounded to 1438000 (1250000 x 1.15 = 1,437,500; nearest 1,000 is 1,438,000, qa confirms the rounding of exact halves against TASK-18 and records it).
4. 200 with no error; the flag follows the rule TASK-5 documents for invalid values and `/api/config` agrees with the price behaviour.
5. Restore both settings at the end.

## Test data
- Settings keys `service_fee_percent`, `show_fee_note`.
