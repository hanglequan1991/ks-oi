## Steps
1. Start the server and open `/bill` in a new context with no cookies and no storage.
2. Read `<html lang>`, the title, the column header row, and the data rows.
3. Read the cookies of the context and the Set-Cookie headers of the page response.
4. Search the page for links and forms; request `/admin`, `/admin/login` and `/api/admin` on the same server.
5. Smoke check of the harness: `GET /api/config` returns 200 JSON; `/bill.js` and `/bill.css` return 200 with their content types.

## Expected results
1. Status 200, `<html lang="vi">`, title and labels in Vietnamese (for example `Khách sạn` as the Hotel column), no login prompt or redirect.
2. The header row has exactly six columns `#`, Hotel, Room, Night, Pricing, Total in that order (Vietnamese words); exactly one `.bill-item` exists, its number is 1, Hotel, Room and Pricing are empty, Night is 1, Total shows a dash or is empty, and its remove button is disabled.
3. No cookie is set and no `Authorization` is needed; the page response has no `Set-Cookie`.
4. The page has no `<form>`, no `<a>` to any `/admin` path and no `tel:` or Zalo link; `/admin`, `/admin/login` and `/api/admin` answer 404 or 405 (no admin function exists on this app).
5. Both assets load; the harness `requests` list shows only GET requests.

## Test data
- Sample data (TASK-16, final prices at the seeded 10 percent fee): `Mộng Hotel` (`mong-hotel`): room `Deluxe` 1,375,000 (base 1,250,000 must never appear), room `Standard` no price. `Sao Hà Nội` (`sao-hotel`): room `Superior` 1,078,000. `Đông Đô` (`dong-do-hotel`): no rooms. `Mộng Review` and `Mộng Hidden` are not published and must never be offered.
