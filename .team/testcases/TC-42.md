## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. It is a Node http server wrapping `createApp` + `mountApi` + `registerBillRoutes` with the fake D1 (`applyMigrations` + `seedApiSample`, TASK-1/TASK-16) and the seeded default settings, serving `public/` (`bill.css`, `bill.js`, `app.css`, `lang.js`) after `npm run build:client` (TASK-34). `requests` records method, URL and body of every request it receives. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).
- The harness also mounts a second sample page rendered through `Layout` (`/sample`, `/en/sample`) so that header, footer, menu and language toggle can be inspected; this sample route is added by qa in `billServer.ts` under TC-40 and is only a test route. Links on real hotel and home pages are covered by the LIVE TC-62.

## Steps
1. Open `/sample`, `/en/sample`, `/bill` and `/en/bill`; collect every `a[href]`, `link[href]` and form action on each page.
2. `GET /sitemap.xml` and `GET /robots.txt` on the server.
3. For `/bill` and `/en/bill` read the response headers and the `<meta name="robots">` tag.
4. Search the source of every JSON response of `/api/config` and `/api/cities` for the text `bill`.

## Expected results
1. No `a[href]` on the sample pages (header, footer, language toggle, menu) points to `/bill` or `/en/bill`; on the bill pages no `a[href]` points to `/bill` (only `Layout`'s canonical and alternate `<link>` tags of the bill page itself may mention it).
2. Sitemap and robots.txt answer 404 (Version 1 has none) or, if present, contain no `bill`.
3. Both bill responses carry `X-Robots-Tag: noindex, nofollow` and the HTML has `<meta name="robots" content="noindex, nofollow">`.
4. The API responses do not mention the billing page.

## Test data
- Sample data (TASK-16, final prices at the seeded 10 percent fee): `Mộng Hotel` (`mong-hotel`): room `Deluxe` 1,375,000 (base 1,250,000 must never appear), room `Standard` no price. `Sao Hà Nội` (`sao-hotel`): room `Superior` 1,078,000. `Đông Đô` (`dong-do-hotel`): no rooms. `Mộng Review` and `Mộng Hidden` are not published and must never be offered.
