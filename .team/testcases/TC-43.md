## Steps
1. Open `/bill` at viewport 1280x800 and add two more rows (3 rows).
2. For each row read the bounding boxes of the Hotel cell, the Total cell and the note box, and of the note label.
3. Repeat on `/en/bill`.
4. Read the text of every note label.

## Expected results
1. Each `.bill-note` is directly below its own data row (its top is at or just below the row bottom, before the next row) and belongs to the same `.bill-item`.
2. The note field's left edge equals the Hotel column's left edge (tolerance 2 px) and its right edge equals the Total column's right edge (tolerance 2 px).
3. The label is exactly `GHI CHÚ` (vi) / `NOTE` (en) for rows 1, 2 and 3: no digit, no row number. Its accessible name does carry the row (`Note, row 2` style).
4. The note label sits in the first column (the `#` column), left of the Hotel column.

## Test data
- Viewport 1280x800 for desktop.
