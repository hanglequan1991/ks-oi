## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. It is a Node http server wrapping `createApp` + `mountApi` + `registerBillRoutes` with the fake D1 (`applyMigrations` + `seedApiSample`, TASK-1/TASK-16) and the seeded default settings, serving `public/` (`bill.css`, `bill.js`, `app.css`, `lang.js`) after `npm run build:client` (TASK-34). `requests` records method, URL and body of every request it receives. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. In row 1 type or paste 600 characters into the note.
2. Type the note `<script>window.__x=1</script><b>bold</b> & "q"` into row 2, the hotel text `<img src=x onerror=window.__x=2>` into row 1's Hotel field and the same kind of text into row 2's Room field; Tab out of each field.
3. Reload the page (draft restore) and read the values again; register a dialog listener for the whole test.
4. Switch to print media (`page.emulateMedia({ media: 'print' })`) and read the printed mirror of the same fields.

## Expected results
1. The first note holds exactly 500 characters (the first 500 of the input, extra characters dropped; paste is also cut).
2. The note and the texts appear literally, tags included, in the inputs and in the print mirror; no `<b>`, `<img>` or `<script>` element exists inside `.bill-item`, `window.__x` stays undefined, and no dialog opens.
3. After reload the restored values are the same literal text (still no markup).

## Test data
- Long text: 600 characters, for example `'a'.repeat(300) + 'b'.repeat(300)`; expected stored text is the first 300 `a` plus 200 `b`.
