## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. It is a Node http server wrapping `createApp` + `mountApi` + `registerBillRoutes` with the fake D1 (`applyMigrations` + `seedApiSample`, TASK-1/TASK-16) and the seeded default settings, serving `public/` (`bill.css`, `bill.js`, `app.css`, `lang.js`) after `npm run build:client` (TASK-34). `requests` records method, URL and body of every request it receives. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. Click the Hotel field of row 1 and type `mo`.
2. Pick `Mộng Hotel` from the list with the mouse.
3. In row 2 type `mong` (no accents), then `dong do`, then `sao ha noi`.
4. In row 3 type `Khách sạn lạ` (not in the list) and click elsewhere (blur); also type `xyzxyz` in row 2 after clearing it and look at the list.
5. Type `Review` and `Hidden` in a row and look at the list.

## Expected results
1. Typing `mo` opens a list that contains `Mộng Hotel` (and no unpublished hotel); the list appears after the debounce without a page reload (wait for the `/api/suggest` response, not a sleep). Picking it puts `Mộng Hotel` in the field and closes the list.
2. `mong` offers `Mộng Hotel`, `dong do` offers `Đông Đô`, `sao ha noi` offers `Sao Hà Nội`.
3. The unknown text `Khách sạn lạ` stays in the field after blur and after reload (free text, no error). `xyzxyz` shows no options or a localised `no results` line.
4. `Mộng Review` and `Mộng Hidden` are never offered.

## Test data
- Sample data (TASK-16, final prices at the seeded 10 percent fee): `Mộng Hotel` (`mong-hotel`): room `Deluxe` 1,375,000 (base 1,250,000 must never appear), room `Standard` no price. `Sao Hà Nội` (`sao-hotel`): room `Superior` 1,078,000. `Đông Đô` (`dong-do-hotel`): no rooms. `Mộng Review` and `Mộng Hidden` are not published and must never be offered.
- Number format: Vietnamese page groups with `.` (1.375.000), English page with `,` (1,375,000). Selectors follow the class contract of TASK-33 / TASK-35 / TASK-37 (`.bill-item`, `.c-hotel input`, `.c-room input`, `.c-night input`, `.c-price input`, `.c-total`, `.badge-edited`, `.btn-reset`, `.c-remove button`, `.bill-note textarea`, `[data-action=add|clear|print|clear-draft]`, `[data-bill-status]`, `[data-bill-summary]`); prefer `getByRole` / aria-label where the dictionary provides it. Wait on conditions (`expect(...).toHaveText`, `waitForResponse`), never fixed sleeps.
