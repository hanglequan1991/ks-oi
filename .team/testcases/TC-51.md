- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. - TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. Start with one row: check the remove button state. Click Add row once.
2. Fill row 1 hotel text `A`, row 2 `B`; add up to 4 rows (`A`..`D`) and remove row 2.
3. Click Add row until 30 rows exist; try to add a 31st (button state, hint text, and a forced click).
4. Remove rows until one remains; try to remove the last one.
5. Check the grand total after removal.

## Expected results
1. A new row is appended at the end with Night 1 and empty fields, numbered in sequence (2, 3, ...).
2. After removing row 2 the rows read `A`, `C`, `D` and are numbered 1, 2, 3; the grand total reflects the removal.
3. At 30 rows Add row is disabled (or refuses) and the hint `Maximum 30 rows` / Vietnamese equivalent shows; `.bill-item` count stays 30. Removing a row re-enables it.
4. With exactly one row its remove button is disabled and clicking does nothing; the row count stays 1.

## Test data
- Sample data (TASK-16, final prices at the seeded 10 percent fee): `Mộng Hotel` (`mong-hotel`): room `Deluxe` 1,375,000 (base 1,250,000 must never appear), room `Standard` no price. `Sao Hà Nội` (`sao-hotel`): room `Superior` 1,078,000. `Đông Đô` (`dong-do-hotel`): no rooms. `Mộng Review` and `Mộng Hidden` are not published and must never be offered.
