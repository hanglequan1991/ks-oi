## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. It is a Node http server wrapping `createApp` + `mountApi` + `registerBillRoutes` with the fake D1 (`applyMigrations` + `seedApiSample`, TASK-1/TASK-16) and the seeded default settings, serving `public/` (`bill.css`, `bill.js`, `app.css`, `lang.js`) after `npm run build:client` (TASK-34). `requests` records method, URL and body of every request it receives. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. With fee 10 percent: row 1 `Mộng Hotel` / `Deluxe` (default 1.375.000, unedited), row 2 `Sao Hà Nội` / `Superior` with price edited to `1.000.000`, row 3 free-text hotel with price `500.000`.
2. Wait for the draft to be saved, close the page.
3. Call `server.setFee(20)` (Deluxe becomes 1.500.000, Superior 1.176.000), reopen `/bill`.
4. Read prices, edited markers and totals; click reset on row 2.
5. Then make the room API fail (`page.route('**/api/hotels/*', abort)`) and reopen.

## Expected results
1. Row 1 shows `1.500.000` (refreshed, no edited marker).
2. Row 2 keeps `1.000.000` with the edited marker; clicking reset now gives `1.176.000`. Row 3 keeps `500.000`.
3. Totals and the grand total use the refreshed values; the draft-restored message warns that prices may have changed.
4. When the room request fails the stored values are kept, the page stays usable and no alarming error is shown.

## Test data
- Fee 20 percent: Deluxe base 1,250,000 -> 1,500,000; Superior base 980,000 -> 1,176,000 (base figures only used for expected values, never searched for in the page).
