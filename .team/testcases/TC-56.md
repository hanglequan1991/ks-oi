## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. It is a Node http server wrapping `createApp` + `mountApi` + `registerBillRoutes` with the fake D1 (`applyMigrations` + `seedApiSample`, TASK-1/TASK-16) and the seeded default settings, serving `public/` (`bill.css`, `bill.js`, `app.css`, `lang.js`) after `npm run build:client` (TASK-34). `requests` records method, URL and body of every request it receives. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. Open `/bill` and record all requests with `page.on('request')` and the harness `requests` list.
2. Fill rows (hotel, room, nights, price edit, notes with distinctive text such as `SECRET-NOTE-731`), add, remove, clear all, clear draft, reload and press Print (stub `window.print`).
3. Search every recorded URL, header and body for the distinctive strings; list every method and path.
4. Search `document.cookie`, `sessionStorage` and every `localStorage` key.

## Expected results
1. Only GET requests occur: the page, `/bill.css`, `/bill.js`, `/app.css`, `/lang.js`, `/api/suggest?q=...&limit=8&lang=..` and `/api/hotels/<slug>?lang=..`; no POST, PUT, DELETE, PATCH, `sendBeacon` or WebSocket.
2. The note text and prices never appear in any URL or body (only the typed hotel text appears in `/api/suggest?q=`, which is allowed and documented).
3. No cookie and no `sessionStorage`; the only `localStorage` key is `hd_bill_v1`.
4. The harness server holds no bill data (the fake D1 tables are unchanged by the session).
