## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. It is a Node http server wrapping `createApp` + `mountApi` + `registerBillRoutes` with the fake D1 (`applyMigrations` + `seedApiSample`, TASK-1/TASK-16) and the seeded default settings, serving `public/` (`bill.css`, `bill.js`, `app.css`, `lang.js`) after `npm run build:client` (TASK-34). `requests` records method, URL and body of every request it receives. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. Open `/bill` and `/en/bill` at 1280 px and at 390 px; locate the bill notes block and the grid.
2. Read the fee note and the disclaimer; compare with the harness settings.
3. Call `server.setSettings({ feePercent: 12.5 })` and reload; then `setSettings({ showFeeNote: false })` and reload; then set a custom disclaimer text and reload.
4. Search the page for `tel:`, `zalo`, `phone`, call buttons and phone-number patterns.

## Expected results
1. The disclaimer (call to confirm prices and availability) and the fee note appear below the grid (after the last row in document order and visually below it) on desktop and mobile, in the page language.
2. The fee note shows `Includes 12.5% service fee` (en) after the change and disappears when `showFeeNote` is false; the disclaimer text follows the settings; the disclaimer appears exactly once.
3. No `tel:` link, no Zalo link, no call button, no phone number anywhere on the page.

## Test data
- Seeded defaults: fee 10, fee note on, agreed disclaimer (TC-4).
