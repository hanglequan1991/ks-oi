## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. Fill 3 rows: row 1 `Mộng Hotel` / `Deluxe`, Night 2, note `Gần biển`; row 2 `Sao Hà Nội` / `Superior` with no note; row 3 free-text hotel with an edited price and a note.
2. Stub `window.print`, click Print / Save PDF and read `[data-bill-date]`; then `page.emulateMedia({ media: 'print' })`.
3. Check visibility of: the print head (title, date), every row, every note, the grand total, the fee note, the disclaimer, header and footer of the site, buttons, inputs, textareas, dropdown lists, edited marker, reset, remove buttons, status message.
4. Also create a PDF with `page.pdf` (Chromium) and check it is produced with at least one page; set the viewport to 500 px wide before printing to check the desktop columns are kept.

## Expected results
1. The print action calls `window.print()` once and the date is set to today's date in the page language before printing.
2. In print media the print head with title and date, all 3 rows (values shown as text mirrors, not input boxes), the grand total, the fee note and the disclaimer are visible, and the page has no phone or Zalo.
3. Row 1 and row 3 show their note under the row with the label NOTE; row 2 shows no note box at all (not even an empty frame).
4. Header, footer, Add / Clear / Print / Clear draft buttons, all `input`, `textarea`, `.combo-list`, `.badge-edited`, `.btn-reset`, remove buttons and the status message are not displayed.
5. The PDF is produced on A4 pages; `.bill-item` has computed `break-inside: avoid` so a row is not split from its note; at a 500 px viewport the print layout still shows the desktop columns, not cards.

## Test data
- Print date check: contains the current year; do not hard-code the date.
