## Steps
1. Set viewport 390x844 (and a second run at 719 and 721 px) and open `/bill`; add 2 rows and fill row 1 (`Mộng Hotel` / `Deluxe`, note).
2. Check the header row visibility; inside each `.bill-item` read the visible parts and their order (number and remove first, Hotel, Room, Night and Pricing side by side, Total, Note).
3. Read the bounding box height of every interactive element: inputs, textarea, Add, Clear all, Print, Clear draft, reset, remove, dropdown options.
4. Check there is no horizontal scroll (`scrollWidth <= clientWidth`).

## Expected results
1. At 390 px and 719 px the column header row is hidden and each row is a card with its own number, a remove action, Hotel, Room, Night and Pricing (side by side), Total and Note; field labels (`.cell-label`) are visible.
2. At 721 px the desktop grid shows (header row visible, no cards).
3. Every interactive element is at least 44 px high (`boundingBox().height >= 44`).
4. No horizontal scrolling; the note label stays `GHI CHÚ` (no row number) in each card.

## Test data
- Viewports: 390x844, 719x900, 721x900. Playwright `mobile` project (Pixel 7) may be used for the 390 run.
