## Preconditions
- Harness (built by qa under TC-40, reused here): `sheet-rag/e2e/support/billServer.ts` exports `startBillServer()` returning `{ url, requests, setFee(percent), setSettings(partial), close() }`. It is a Node http server wrapping `createApp` + `mountApi` + `registerBillRoutes` with the fake D1 (`applyMigrations` + `seedApiSample`, TASK-1/TASK-16) and the seeded default settings, serving `public/` (`bill.css`, `bill.js`, `app.css`, `lang.js`) after `npm run build:client` (TASK-34). `requests` records method, URL and body of every request it receives. No Cloudflare credentials are needed.
- TASK-26..TASK-39 are done (page, bundle, styles, routes, Playwright tooling). The test file starts its own server on a free port in `beforeAll`, closes it in `afterAll`, and uses a fresh browser context per test (empty localStorage). Browser: Chromium (`npx playwright install chromium`).

## Steps
1. Create a context with `javaScriptEnabled: false` and open `/bill`, then `/en/bill`.
2. Read the noscript message, the header row and the grid area.

## Expected results
1. A visible message states that JavaScript is required, in Vietnamese on `/bill` and English on `/en/bill`.
2. The server-rendered title, header row and the fee note and disclaimer are still shown; no data rows and no script error.
3. With JavaScript enabled the message is not visible.

## Test data
- Sample data (TASK-16, final prices at the seeded 10 percent fee): `Mộng Hotel` (`mong-hotel`): room `Deluxe` 1,375,000 (base 1,250,000 must never appear), room `Standard` no price. `Sao Hà Nội` (`sao-hotel`): room `Superior` 1,078,000. `Đông Đô` (`dong-do-hotel`): no rooms. `Mộng Review` and `Mộng Hidden` are not published and must never be offered.
